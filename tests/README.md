# 离线回归测试

全部不联网、不需要账号，直接跑即可：

```bash
for t in tests/test_*.py; do python "$t" || break; done
```

| 文件 | 覆盖内容 |
| --- | --- |
| `test_ui.py` | 建窗、测试模式、题目列表、四种题型的答案读写、设置保存 |
| `test_protocol.py` | 用合成的雨课堂报文验证签到、收题去重、自动答题、题目锁定、下课 |
| `test_ai.py` | 对着本地假服务验证请求体、返回解析、401/429 提示、断线重试 |
| `test_batch.py` | 课件截图下载与缓存、批量解题的并发上限、失败隔离、中途停止 |

`test_ui.py` / `test_batch.py` 需要图形环境（会真的建窗口）。
